# Full Pipeline Run

Run each process in its own terminal tab, in order.

---

## Process 1 — Mosquitto MQTT Broker

```bash
mosquitto
```

Broker listens on **localhost:1883**.  
Leave this terminal open — all other processes connect through it.

---

## Process 2 — Sensor Simulator

```bash
cd emb-ai-pred-main
python sensor_simulator.py --fault bearing_wear
```

Publishes to **sensor/vibration** every 1.28 s.  
Payload: `{ "vibration_x": [...512 floats...], "temperature": float, "current_a": float, "fault_injected": str }`

Other available fault types: `normal`, `imbalance`, `misalignment`, `critical`

---

## Process 3 — Inference Engine

```bash
python inference_engine.py
```

Subscribes to **sensor/vibration**, runs INT8 TFLite model, publishes to **inference/result**.  
Payload: `{ "class": str, "confidence": float }`

---

## Process 4 — Node-RED Dashboard (Browser)

```bash
node-red &
```

1. Open **http://localhost:1880**
2. Hamburger menu → **Import** → select `nodered-dashboard-flow.json`
3. Click **Import**, then **Deploy**
4. Open **http://localhost:1880/ui**

Dashboard widgets:

| Widget | Source topic | Data |
|---|---|---|
| Live Vibration Waveform | `sensor/vibration` | Canvas chart, 128 decimated samples, redraws every 1.28 s |
| Fault Class | `inference/result` | Colour-coded label — green NORMAL / orange WARNING / red CRITICAL |
| Confidence Gauge | `inference/result` | 0–100 % arc gauge |
| Motor Temp | `sensor/vibration` | Live °C reading |
| Phase Current | `sensor/vibration` | Live A reading |
| Alert History | `inference/result` | Scrollable table, non-normal faults only, newest first, up to 50 rows |

---

## Process 5 — Alert Manager (optional)

```bash
export TELEGRAM_BOT_TOKEN=your_token
export TELEGRAM_CHAT_ID=your_chat_id
python alert_manager.py
```

Subscribes to **inference/result**.  
Fires a Telegram message and writes to `alerts.db` (SQLite) when confidence > 75 % and class != normal.
